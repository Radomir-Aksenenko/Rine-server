# Rine

Сервер Minecraft Java Edition 26.3 (протокол 777), написанный на Rust с нуля. Обычный ванильный клиент заходит на него как на любой сервер, а внутри работает другая модель исполнения: данные хранятся плоско, всё, что видят несколько игроков, кодируется один раз, тяжёлая работа идёт параллельно на всех ядрах.

Архитектура и причины решений: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Форматы пакетов, вытащенные из исходников 26.3: [docs/spec](docs/spec).

## Запуск

```bash
cargo run --release -p rine-server
```

При первом запуске появится `rine.toml` с настройками (порт, MOTD, дальность прорисовки, сид, режим игры). Мир сохраняется в папку `world/`, остановка через `stop` в консоли или Ctrl+C.

Подключение: Minecraft 26.3, адрес `localhost`. Пока работает только offline-режим (`online_mode = false`).

## Что уже есть

- Полный путь входа: handshake, статус для списка серверов, логин со сжатием, configuration с реестрами и тегами из ванильного ядра (клиент берёт данные из своего встроенного пакета, сервер шлёт только имена).
- Генератор мира: рельеф с горами, океанами и реками, пещеры, около двадцати биомов, руды по высотам, деревья, трава и цветы. Чанк генерируется за ~0,8 мс, чанки не зависят друг от друга и строятся параллельно.
- Свет (небо и блоки), карты высот, сохранение чанков (LZ4).
- Несколько игроков: видят друг друга, движение, присед, бег, экипировка, таб-лист с пингом, чат.
- Ломание и установка блоков с подтверждением последовательностей, ванильные лут-таблицы, падающий песок и гравий, выпавшие предметы и их подбор.
- TNT: поджиг, цепные реакции, взрывы пачкой за тик.
- Урон от падения и взрывов, смерть и возрождение.
- Команды: `/gamemode`, `/tp`, `/give`, `/time`, `/tps`, `/spawn`, `/list`, `/seed`, `/tnt <кол-во>` (стресс-тест).
- Мост для Java-плагинов (крейт `rine-plugin`) с подмножеством Bukkit API.

## Проверка

`rine-testbot` это headless-клиент на том же протоколе. Он проходит логин и configuration, разбирает каждый чанк до байта и умеет запускать сотни ботов разом:

```bash
cargo run --release -p rine-testbot -- 127.0.0.1:25565 --bots 200 --walk --seconds 30
```

Парсер бота сверен с настоящим ванильным сервером 26.3: ноль ошибок разбора.

## Честно о границах

- Генератор свой, а не побитовая копия ванильного: по тому же сиду ландшафт будет другим.
- Мобов, крафта, сундуков, редстоуна и голода пока нет. Это следующие этапы.
- С миллионом активированных TNT узким местом станет клиент: ванильный клиент не рисует столько сущностей. Сервер считает взрывы пачкой и рассылает изменения блоков одним пакетом на секцию.
- Плагины работают через встроенную JVM (JNI). Ускорение плагинов достигается тем, что они не стоят на пути тика: события копятся и уходят пачкой, синхронно вызываются только те, на которые плагин подписан. Переписывать байткод плагинов на лету смысла мало, HotSpot и так компилирует его в машинный код.
