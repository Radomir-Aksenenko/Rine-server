# Rine

А что тут смотреть? Ну, сервер на расте. Ну, самый быстрый. Ну, такой же, как ванила. Ну, поддерживаем несколько версий. Хотя нет, пока только одну. Что тут смотреть-то?

Ну, если хотите запустить наше ядро, ну так уж и быть, вот вам мини-гайд.

## Мини-гайд

1. Поставьте Rust (stable) через [rustup](https://rustup.rs).
2. Соберите и запустите:

   ```bash
   cargo run --release -p rine-server
   ```

3. При первом запуске рядом появится `rine.toml`. Там порт (`bind`, по умолчанию `0.0.0.0:25565`), MOTD, дальность прорисовки, сид, режим игры, опы и вайтлист. Поменяли, перезапустили.
4. Зайдите клиентом Minecraft Java **26.3** на `localhost`. Других версий пока нет.
5. Пока работает только offline-режим (`online_mode = false`), аккаунты Mojang не проверяются.
6. Мир лежит в папке `world/`. Остановить сервер: `stop` в консоли или Ctrl+C.

Хотите посмотреть, сколько он держит? Запустите сотню-другую ботов:

```bash
cargo run --release -p rine-testbot -- 127.0.0.1:25565 --bots 200 --walk --seconds 30
```
