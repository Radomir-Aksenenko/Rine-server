# Rine: правила для агентов

Перед любым кодом прочитай [docs/PHILOSOPHY.md](docs/PHILOSOPHY.md). Здесь только выжимка.

- Наблюдаемое поведение совпадает с ванильным 26.3 один в один: пакеты, состояние мира, сохранения, тексты команд, тайминги в тиках, порядок событий.
- Баги и странности ванилы сохраняем, если на них опираются игроки. Не чиним.
- Перед кодом механики: найти класс в `Paper-26.3/paper-server/src/minecraft/java/net/minecraft/`, прочитать целиком, выписать порядок действий и граничные случаи. По памяти не писать.
- Метки `// Paper`, `// CraftBukkit`, `// Spigot` это не ваниль.
- «Как в ваниле» относится только к результату, не к алгоритму. Ванильный алгоритм, скопированный как есть, медленный, это долг, а не решение.
- Скорость такой же закон, как паритет. Не пожелание.
- Прежде чем оставить медленную реализацию, ищем быстрый способ: структуры данных, предвычисление, кеши, инкрементальные обновления, пакетная обработка, параллельность с детерминированным слиянием, SIMD, ленивость, перенос работы из тика. «Не вышло с первой попытки» не причина.
- Медленный путь допустим только как крайняя мера. Тогда смягчаем последствия, пишем комментарий в коде и записываем долг в `docs/PERF-DEBT.md` с перечнем отвергнутых вариантов. Молча оставить медленную копию запрещено. Владельцу сообщаем в отчёте.
- Оптимизация, которая меняет видимое поведение, не делается. Либо она за настройкой, выключенной по умолчанию.
- Отступления от ванилы перечислены в PHILOSOPHY.md, раздел 5. Новое отступление согласовать с владельцем.
- Горячий путь тика (50 мс): без аллокаций на сущность или блок, без строковых сравнений в циклах, без I/O, без `unwrap` и `panic`. Пакет кодируется один раз на всех зрителей.
- Чанки и I/O работают вне тика, тик получает готовое.
- Сверка: `cargo test -p <крейт>`, golden в `tools/noise-golden` и `tools/cmdtree`, `rine-testbot ... --expect-clean`.
- Порт 25565 занят живым сервером владельца. Тесты только на других портах.
- Комментарии в коде по-английски, коротко. Документы и тексты для игроков по-русски.
- Коммит только со своими файлами, `тип(область): суть` по-английски, с `Co-Authored-By`.
