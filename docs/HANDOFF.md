# Rine: состояние проекта и план (для новой сессии)

Обновлено: 2026-11-15.

## Что это

Rine: сервер Minecraft Java 26.3 на Rust. Логика игры ванильная, исполнение своё
(параллельность, пакеты кодируются один раз, батчи изменений блоков). Клиент 26.3
подключается и играет. Основная ветка `master`.

## Крейты

- `rine-protocol`: кодеки, NBT, фреймы, id пакетов.
- `rine-data`: таблицы блоков, предметов, реестров, тегов из jar 26.3.
- `rine-world`: чанки, Anvil-хранилище, свет; `gen/` вызывает `rine-worldgen`
  (ванильный рельеф) и временные свои деревья, цветы и руды поверх.
- `rine-worldgen`: побитовый порт ванильной генерации, всё со сверкой против jar
  (`tools/noise-golden`):
  - шумы и рандом, плотность, биомы, аквиферы, жилы, правила поверхности,
    карверы (пещеры и каньоны): **0 расхождений**;
  - фичи (`src/feature/`): руды (~0,01% расхождений, остаток зависит от порядка
    обхода чанков), деревья (~0,03%, листва `distance` и лианы), простые
    растения и двойные растения (сходятся), диски, столбики, источники, лёд,
    селекторы, карты высот;
  - `pipeline.rs`: кэш полной генерации, **медленный** (454 мс/чанк в 1 поток),
    к серверу пока не подключён.
- `rine-server`: игровой цикл, сеть (обработка пакетов между тактами), копание
  со звуками по ванильной схеме, установка блоков, соседние обновления, жидкости
  и вёдра, сундуки, верстак, печь, голод, урон от падения, атака с откидыванием,
  прочность, сохранение игроков, опки (`run/ops.txt`), JVM-плагины (минимально),
  TNT (100k без лагов, 1M ещё лагает: p99 96 мс), бенчмарк `game::bench`.
- `rine-testbot`: боты со строгой проверкой пакетов.

## Запуск

- Сервер: `cargo build --release -p rine-server`, затем в `run/`:
  `../target/release/rine.exe` (порт 25565, мир `run/world`, старый мир в
  `run/world-old-*`).
- Проверка: `target/release/rine-testbot.exe 127.0.0.1:25565 --bots 2 --seconds 10 --expect-clean`.
- Бенч TNT: `cargo test --release -p rine-server bench_tnt -- --ignored --nocapture`.
- Ванильный сервер для сверок: `vanilla-data/` (jar 26.3, порт 25566).
- Клиент 26.3 для `javap`: `E:\PC-Storage\AppData\FreesmLauncher\libraries\com\mojang\minecraft\26.3\minecraft-26.3-client.jar`.

## Дальше по порядку

1. Влить ветку агента выше, проверить `cargo test -p rine-worldgen`.
2. Переделать `pipeline.rs`: декорировать каждый чанк один раз, когда готовы 3x3
   прото-чанки; финальный чанк, когда декорированы 3x3; цель ~10 мс/чанк;
   ускорить `Overworld::generate` (сейчас 31 мс с карверами).
3. Подключить pipeline в `rine-world/src/gen/mod.rs` вместо временных
   деревьев/цветов/руд, пересоздать мир.
4. Оставшиеся фичи: кораллы, сталактиты, жеоды, скалк, данжи, огромные грибы,
   корни, затем структуры (деревни, шахты, крепости).
5. Руды: остаток расхождений. Гипотезы проверены (биомный зум, Paper-патчи,
   сиды); остаётся порядок записи пересекающихся жил между чанками.
6. TNT, этап 3: SoA-хранение сущностей, сетка по секциям, общий кэш лучей.
7. Атрибуты оружия (сейчас всё бьёт как кулак), мобы, Незер и Энд.
8. Чистка: 54 предупреждения, `unwrap()`, большие файлы, строковые сравнения в
   горячих путях (`neighbors.rs`).

## Правила работы

- Порт только из исходников Paper 26.3 (`Paper-26.3/paper-server/src/minecraft/java`),
  при `// Paper` сверять байткод ванильного jar через `javap`.
- Каждая часть генерации сверяется с ванилью (golden), цель 0 расхождений.
- Агенты работают в worktree, файлы сверок с уникальными именами.
- Порт 25565 занят живым сервером владельца, тесты агентов на других портах.
